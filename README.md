# Отчёт по авансам подрядчиков

CLI на Python 3.10+ без внешних зависимостей. Входные CSV находятся в `data/`. Не публиковать данные и решение.

Запуск из корня проекта:

```sh
python report.py --date 2026-11-10 --data data --out output
python -m unittest discover -s tests -v
```

На Windows вместо `python` можно использовать `py -3`. Выходные файлы: `output/works.csv` и `output/contracts.csv` (UTF-8 BOM, разделитель `;`, суммы в рублях). Входные файлы не изменяются при использовании отдельного каталога вывода. Дата включительна.

### Поля отчёта

`price` — исходная цена; `effective_price` — цена с учётом отмен; `status` — состояние на дату отчёта. `direct_paid` — чистые целевые платежи; `advance_allocated` — распределённые общие платежи; `paid` — их сумма; `remaining` — неоплаченная часть цены (включая будущие работы); `due_now` — неоплаченная часть принятых работ; `excess` — целевые деньги сверх актуальной цены, в том числе по отменённым работам.

По договору: `contract_amount` — исходная сумма; `listed_price` — сумма всех цен работ; `accepted_price` — цена принятых работ; `gross_paid` — перечислено; `refunded` — возвращено; `net_paid` — чистые платежи; `allocated_paid` — отнесено к работам; `unallocated_advance` — свободные деньги; `queued` — заведённые, но ещё не перечисленные платежи; `net_balance` — актуальная цена минус чистые платежи (отрицательное значение означает общий избыток). Остальные суммы агрегируются из работ. Свободный аванс не является дополнительным долгом.
